Step 1: Run the UI & Node Server Proxy (Port 3000)
Open a terminal in the project root directory:
code
Bash
# 1. Install Node.js dependencies
npm install

# 2. Start the development server
npm run dev
The application will be accessible in your browser at http://localhost:3000.
Step 2: Run Your Local Agentic AI FastAPI Backend (Port 8000)
In a separate terminal window, set up and run your Python FastAPI backend (e.g. main.py):
code
Bash
# 1. Create and activate a Python virtual environment
python -m venv venv

# On Linux/macOS:
source venv/bin/activate

# On Windows (PowerShell / CMD):
venv\Scripts\activate

# 2. Install FastAPI, Uvicorn, and Multipart support
pip install fastapi uvicorn pydantic python-multipart

# 3. Launch the Uvicorn backend server on port 8000
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
Step 3: Connect UI to Your Live Local Backend
Open http://localhost:3000 in your browser.
In the top navigation header, click the Settings button (Agentic Simulator).
Select Live Local FastAPI (http://127.0.0.1:8000).
Click Save & Apply Settings.
All chat requests (POST /chat) and document uploads (POST /upload) will now proxy directly to your local FastAPI agentic backend.
